# MouseSteering

This program is a simple **WinExe .NET** application that allows using a mouse inside a window's boundary as a **horizontal controller input**, while also **holding that controller input**, making it ideal for racing games.

## Requirements

- **.NET Runtime 9 or later**
- **vJoy**
- **64-bit Windows environment**

## Installation
You can either get the pre-compiled exe from the [Releases](https://github.com/happysmaran/MouseSteering/releases) page, or you can download the source code from this repository and simply run the main file.
